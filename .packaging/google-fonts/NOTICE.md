# Self-hosted Google Fonts

Added by Stateloop packaging so players' browsers never contact Google. The files are the exact
stylesheets and WOFF2 files Google Fonts serves for the game's own font request; each family keeps
its licence from google/fonts at e7db6ca603fd4862010383ff17ffd6cc4ffac1c0.

- Barlow Condensed: OFL-1.1 (google/fonts `ofl/barlowcondensed/OFL.txt`)
- Saira Stencil One: OFL-1.1 (google/fonts `ofl/sairastencilone/OFL.txt`)

Source stylesheets:
